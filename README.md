# 🎬 MovieHouse | موفي هاوس
> **منصة أفلام ومسلسلات سينمائية باشتراك رمزي عبر متجر سلة (Frontend Demo)**  
> *A Netflix-style streaming platform demo integrated with Salla store nominal subscriptions.*

---

## 🌟 فكرة المشروع (Project Overview)

منصة رقمية مستوحاة من واجهة **نتفليكس (Netflix)** تتيح للمشتركين متابعة أحدث الأفلام والمسلسلات العربية، الهوليودية، ومسلسلات الأنمي بدقة **4K Ultra HD** وبدون أي إعلانات مزعجة.  

تعتمد المنصة نموذج عمل مبتكر وبسيط: **الاشتراك بمبلغ رمزي يبدأ من 9.99 ر.س فقط عبر متجر معتمد في منصة سلة (Salla)**، واستلام كود تفعيل رقمي فوري لتنشيط الحساب ومتابعة المحتوى مباشرة.

---

## 🚀 المميزات الرئيسية (Key Features)

1. **دعم ثنائي اللغة والاتجاه (Full Arabic RTL & English LTR):**
   - تبديل فوري بضغطة زر بين العربية والإنجليزية مع ضبط تلقائي للخطوط والاتجاهات (`dir="rtl"` و `dir="ltr"`).

2. **تجربة سينمائية Netflix-Style:**
   - واجهة داكنة راقية (Obsidian Dark Theme) مع تأثيرات زجاجية (Glassmorphism) ولمسات سينمائية.
   - **Hero Billboard**: عارض دعائي ضخم للأعمال الحصرية مع شارات الجودة (4K HDR, Dolby Atmos, 16+).
   - **قائمة توب 10 (Top 10 Today)**: تصميم رقمي ضخم ومميز لأكثر الأعمال مشاهدة في السعودية والخليج.
   - صفوف وتصنيفات متعددة (الأكثر رواجاً، روائع السينما العربية، أفلام هوليوود، مسلسلات الأنمي والفانتازيا، متابعة المشاهدة).

3. **مشغل فيديو متقدم وتفاعلي (Custom Video Player):**
   - تشغيل حقيقي لمقاطع فيديو عالية الدقة مع تحكم كامل.
   - تقديم وتأخير 10 ثوانٍ، شريط تقدم زمني، تحكم بالصوت.
   - **زر تخطي المقدمة (Skip Intro)** يظهر تلقائياً أثناء شارة البداية.
   - قائمة اختيار الترجمة ولغة الصوت (عربي، إنجليزي).
   - مبدل دقة الفيديو (4K UHD, 1080p, 720p) ومتحكم سرعة التشغيل (0.75x, 1x, 1.25x, 1.5x).
   - زر التبديل لملء الشاشة ومتابعة الحلقات.

4. **باقات موفي هاوس وتكامل متجر سلة (MovieHouse Plans via Salla):**
   - شرح نموذج العمل المكون من 3 خطوات: (1) الشراء من متجر سلة -> (2) استلام الكود الرقمي آلياً عبر SMS/واتساب -> (3) التفعيل الفوري والمشاهدة.
   - **باقات موفي هاوس الرمزية (MovieHouse Plans):**
     - باقة موفي هاوس الشهرية: 9.99 ر.س (شاشة واحدة 1080p).
     - باقة موفي هاوس VIP ربع سنوية (الأكثر طلباً): 24.99 ر.س (شاشتان 4K UHD).
     - باقة موفي هاوس العائلية السنوية: 79.99 ر.س (4 شاشات 4K HDR).
   - نموذج تفاعلي فوري لإدخال كود الطلب مع تأثير احتفالي (Confetti 🎉).

5. **أكواد تجريبية سريعة (Demo Activation Codes):**
   - `SALLA-VIP-2024` (باقة VIP ربع سنوية)
   - `SALLA-MONTHLY-88` (الباقة الشهرية)
   - `SALLA-GOLD-VIP` (الباقة السنوية الذهبية)

6. **البحث السريع والفلترة الحية (Instant Search & Filters):**
   - بحث فوري في العناوين، الممثلين، والمخرجين.
   - فلترة حسب نوع المحتوى (أفلام، مسلسلات) وحسب التصنيف والنوع (أكشن، دراما، كوميديا، تاريخي...).

7. **قائمتي المفضلة (My Watchlist):**
   - حفظ وإزالة الأعمال مع التخزين في `localStorage`.

8. **تبديل الملفات الشخصية (Profile Switcher):**
   - ملفات مخصصة لأفراد العائلة مع ملف مخصص للأطفال (Kids).

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend:** React 18, TypeScript, Vite
- **Styling:** Tailwind CSS, PostCSS, Custom Animations
- **Icons:** Lucide React
- **Animations & Effects:** Canvas Confetti
- **Deployment:** Vercel via GitHub Actions
